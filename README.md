# Student Record System (C)
A command-line application built in C to manage student records. This is a portfolio project demonstrating mastery of C fundamentals, including memory management, structs, arrays, and control flow.

## Features
- Add new student records (Name, Age, GPA)
- View all existing student records
- (More features coming soon...)

## How to Run
Compile the `main.c` file using GCC:
```bash
gcc main.c -o app
./app
```
